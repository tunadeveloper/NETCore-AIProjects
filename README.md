# 🧠 AI Projects - ASP.NET Core

Bu repo, geliştirmiş olduğum **20 farklı yapay zeka projesinden** oluşan kapsamlı bir koleksiyondur.  
Projeleri hazırlarken **ASP.NET Core** teknolojisini kullanarak yapay zeka API’leriyle entegrasyonlar yaptım.  
Her projeyi, gerçek hayattan senaryolara uygulanabilecek şekilde tasarladım ve farklı AI servislerini deneyimledim.  

Her proje, **NLP (Doğal Dil İşleme)**, **Görüntü İşleme**, **Ses İşleme** ve **Veri Analizi** kategorilerinde gerçek dünyadan örnekler içerir.  

---

## 🚀 Teknolojiler
- **Backend:** .NET 6-7-9, Entity Framework Core  
- **AI Servisleri:** OpenAI (GPT, Whisper, DALL·E), Google Cloud Vision, Tesseract OCR  
- **Veritabanı:** SQL Server  
- **Diğer:** Swagger, HtmlAgilityPack, PdfPig, Newtonsoft.Json, System.Speech, RapidAPI
